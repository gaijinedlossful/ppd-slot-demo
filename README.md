# ППД-34/38: старая модель на штатных ресурсах

Пример составного оружия для модов Enlisted: старый корпус ППД-34/38
с обычным барабаном, без собственных моделей, текстур, скриптов и launcher.

[Готовый мод на Sandbox](https://sandbox.enlisted.net/post/Pv8SMW6eLqTX8egG/).
В этом репозитории — сокращённая версия исходников с тем же способом сборки.

## Запуск

1. Скачайте исходники и поместите `entities.blk`, `scene.blk` и этот README
   в папку `Enlisted/userGameMods/ppd_slot_demo/`.
2. Запустите штатный `modsEditor.bat`, выберите `ppd_slot_demo` и начните тест миссии.
3. Подберите ППД-34/38 возле пехотного спауна на советском полигоне
   (X=-548.5, Y=11.21, Z=151). Появление настроено без задержки.

## Устройство и перенос

Скрытый ППД-40 ДСЗ служит носителем скелета и анимаций. Старый корпус и
барабан — два `weapon_mod` на одном штатном слоте `bayonet`, с отдельными
матрицами. На земле барабан показан декоратором.

Для переноса скопируйте все определения `ppd_slot_demo*` из [entities.blk](entities.blk)
в свой мод и используйте предмет `ppd_slot_demo_gun_item`. Пример размещения —
[scene.blk](scene.blk). Override `enlisted_player` нужен только для быстрого спауна.

Компактный вариант проверен локально в игре. Хват, перезарядка и прицеливание
остаются от ППД-40 ДСЗ; возможен небольшой просвет между пальцами и барабаном.
При переносе на другое оружие потребуются проверка слотов и новая калибровка.
